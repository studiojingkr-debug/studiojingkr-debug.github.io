# 스튜디오 징 | Studio Jing

스튜디오 징은 일상에 도움이 되는 모바일 앱을 개발합니다.

## 홀리모닝

홀리모닝은 성경 퀴즈를 풀어 알람을 해제하는 알람 앱입니다.

- 원하는 시간과 반복 요일에 맞춰 알람 설정
- 퀴즈를 풀어 알람 해제
- 회원가입 없이 이용
- 알람 정보와 앱 설정을 기기에 저장

현재 출시를 준비하고 있습니다.
